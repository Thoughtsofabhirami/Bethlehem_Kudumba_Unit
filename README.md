# Bethlehem_Kudumba_Unit
Beginner friendly python learning voyage through your favorite movies!
It is a notebook-based learning project organized into scenes. Each scene guides the learner through a sequence of tasks and activities.

## Repository structure

- `BKU_00_Setup.ipynb` — setup and learning activities for Scene 00.
- `rewards/` — encrypted reward files associated with individual scenes.
- Additional scene notebooks and reward files will be added as the project develops.

## Opening the notebooks

1. Open a notebook in Google Colab.
2. Run the setup cells in order.
3. Follow the instructions and complete the exercises in each scene.

## Reward system

Scene rewards are stored as encrypted `.bin` files. The notebook retrieves the relevant file and attempts to unlock it using the answer supplied by the exercise.

Reward answers are not listed in this README.

## Project status

Scene 00 is the initial scene. More scenes and rewards will be added as development continues.
